API / Extensão Chrome

Servidor local que entrega os Gmails disponíveis e faz push de cada código recebido para a tua extensão.

Endpoints

  • GET /api/available — Gmails disponíveis (verdes)
  • GET /api/codes?email=... — códigos de um Gmail
  • GET /api/latest?email=... — último código
  • GET /api/sms — números SMS ativos (telefone + último OTP)
  • GET /api/sms/latest — último OTP recebido (telefone + código)
  • GET /api/flow — Gmails comprados ativos (e-mail, código, cota e exhausted)
  • GET /api/flow/latest — último código de Gmail comprado
  • POST /api/flow/buy — compra outro Gmail; body { service_id?, max_price_cents? }
  • WS /ws — push em tempo real: código de Gmail, OTP de SMS e código de Gmail comprado

Mande o token em ?token=... ou no header X-Token.
